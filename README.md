LUNCHSPLIT Bill Splitter Application

This is a Bill Splitter application built in C# that allows users to calculate bill totals, taxes and split the cost among attendees based on various splitting techniques. After splitting
the program formats the final result into a readable receipt. 

Features:
1. Accurate SubTotal calucation (Tips, taxes etc)
2. Splitting techniques (by weight, equal split)
3. Validation
4. Formatting Receipt

Testing

The entire application is built on TDD (Test-Driven Development). Each module is slowly built from the ground up by testing all the features with a robust test library
